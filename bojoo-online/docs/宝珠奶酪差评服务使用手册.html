版本: 1.0 更新日期: 2026-05-15 适用对象: 店长、运营、管理层 — 无需技术背景

一、这个系统是做什么的

宝珠奶酪差评服务是一个自动化的差评监控与分析系统，部署在公司服务器上，7×24 小时运行。它做两件事：

1. 自动采集三平台差评

系统每天自动从以下平台抓取差评数据，合并到一个数据库里：

平台 采集方式 差评定义
大众点评 API 直连 ≤3 星
美团外卖 API 直连 ≤3 星
饿了么 影刀 RPA 自动化 ≤3 星

2. 提供两种使用方式

  • 差评周报：每周日自动推送一份汇总报告到企微群
  • 差评机器人：在企微群里直接@机器人提问，即时获取差评数据

二、差评周报（每周自动推送）

推送时间和方式

  • 时间: 每周日自动推送
  • 地点: 企微群
  • 内容: 上周日到本周日（完整一周）的新增差评汇总

周报包含什么

第一部分：概览 - 本周差评总数，与上周对比（环比变化） - 累计差评总量 - 各平台差评分布（大众点评 / 美团 / 饿了么） - 问题分类分布（产品质量、服务态度、分量问题等） - 差评门店 TOP5 - 多平台同时出现差评的门店预警

第二部分：差评明细 - 逐条列出本周每一条差评 - 每条包含：门店名 + 平台 + 星级 + 时间 + 内容摘要（前 30 字） - 差评数量多时自动分多条消息发送

第三部分：Excel 附件 - 完整差评明细表（Excel 格式），保存在服务器上，可随时查阅

示例

# 宝珠奶酪 · 差评周报
> 周期：2026-05-10（周日）~ 2026-05-15

- 本周差评：26 条 (-27, 环比 -51%)
- 累计差评：135 条

## 各平台分布
- 美团外卖：5条
- 饿了么：21条

## 问题分类分布
- 其他：22条
- 产品质量：3条
- 分量问题：1条

## 差评门店 TOP5
1. 西直门凯德MALL店：7条
2. 望京合生麒麟社店：5条
...

注意事项

  • 周报只统计新增差评，不会重复统计历史数据
  • 如果某周差评数量为 0，也会正常推送（显示"本周 0 条"）

三、差评机器人（群内即时互动）

机器人是什么

差评机器人是挂在企微群里的一个 AI 助手。你不需要记命令、不需要写 SQL，用平时说话的方式提问就行。

你能问什么

下面是真实的使用场景，你想怎么说就怎么说，不需要"标准格式"：

你可以这样问 机器人会回答

四、常见问题

Q: 为什么没有收到周报推送？

可能原因： 1. Cookie 过期导致采集失败（系统会发送 Cookie 过期告警） 2. 企微群被解散或机器人被移出 3. 服务器临时故障

处理方法： - 检查企微群是否有 Cookie 过期告警 - 联系技术负责人检查服务器状态 - 手动触发推送（技术负责人操作）

Q: 机器人不回复了怎么办？

可能原因： 1. 机器人离线（服务器或 Dify 服务异常） 2. 数据库文件损坏 3. 企微机器人接口失效

处理方法： 1. 在群里发一条简单消息测试，如"你好"，看是否有回复 2. 如果完全无反应，联系技术负责人 3. 如果回复很慢，可能是服务器负载高，稍等即可

Q: 机器人回复的内容不准确怎么办？

如果你发现机器人回答的数据有问题（比如差评数不对、门店匹配错了），可以：

  1. 直接指出问题：在群里说"这个数据不对，XX 店不应该有差评"
  2. 换一种问法再试：比如"西直门差评"换为"西直门凯德MALL差评"
  3. 联系技术负责人调教机器人

Q: 机器人能"调教"吗？

可以的。机器人的行为是可以调整的：

可调内容 说明 操作人
门店匹配规则 如果某个店名总是匹配不到或匹配错了，可以调整匹配关键词 技术负责人
查询命令 可以增加新的查询功能，比如"昨日对比"、"特定产品差评" 技术负责人
回复话术 机器人的回复风格可以调整（更正式 / 更简洁） 技术负责人
场景手册 上面列出的提问场景不是固定的，实际使用中发现新的问法会持续补充 技术负责人
严重度判定 高危差评的判定标准可以调整 技术负责人 + 运营
问题分类 可以增加新的问题分类，或调整现有分类规则 技术负责人 + 运营

调教方式：在群里直接反馈问题，技术负责人会在后台调整配置。不需要你自己操作代码。

Q: 差评是怎么定义的？

三个平台统一标准：≤3 星（含 3 星）的评价算作差评。

Q: 数据采集的时间

  • 每日自动：每天 00:00 自动运行采集
  • 周报推送：每周日推送

Q: 数据会丢失吗？

数据存储在服务器本地 SQLite 数据库中，每周有定时备份。即使采集脚本出问题，历史数据不会丢失。
