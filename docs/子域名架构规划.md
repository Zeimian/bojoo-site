## 二、Domain 2 子域名架构详解

### 2.1 核心思路

**所有子域名共用一套 Vercel 项目，通过不同子域名路由到不同 HTML 页面。**

为什么选这个方案：
- ✅ Vercel 天然支持通配符子域名（`*.yourdomain.online`）
- ✅ 免费额度充足（个人版 100GB 带宽/月，团队版更多）
- ✅ 自动 HTTPS，无需操心证书
- ✅ 部署极简：推代码到 GitHub → 自动构建部署
- ✅ 每个子域名本质是一个独立的 HTML 文件，维护简单

### 2.2 DNS 配置

在你的域名服务商（阿里云/腾讯云等）添加以下 DNS 记录：

| 类型 | 主机记录 | 记录值 | 说明 |
|------|---------|--------|------|
| CNAME | `@` | `cname.vercel-dns.com` | 主域名 xxx.online 指向 Vercel |
| CNAME | `*` | `cname.vercel-dns.com` | **通配符子域名**，所有子域名都指向 Vercel |

⚠️ **关键：** 通配符 `*` 是核心，有了它之后你添加任意子域名（`cost`、`bi`、`sop`...）都无需再改 DNS。

### 2.3 Vercel 项目结构

```
your-portal/
├── public/
│   ├── index.html          ← 主导航页（门户首页）
│   ├── cost.html           ← 成本机器人指南
│   ├── learn.html          ← OpenClaw 学习站（可 iframe 嵌入或跳转）
│   ├── sop.html            ← SOP 模板库
│   ├── bi.html             ← BI 数据看板
│   └── ... (更多页面)
── vercel.json             ← Vercel 路由配置
└── README.md               ← 说明文档
```

### 2.4 Vercel 路由配置 (vercel.json)

```json
{
  "rewrites": [
    { "source": "/", "destination": "/index.html" },
    { "source": "/cost", "destination": "/cost.html" },
    { "source": "/learn", "destination": "/learn.html" },
    { "source": "/sop", "destination": "/sop.html" },
    { "source": "/bi", "destination": "/bi.html" }
  ],
  "headers": [
    {
      "source": "/(.*)",
      "headers": [
        { "key": "Cache-Control", "value": "public, max-age=3600, s-maxage=86400" }
      ]
    }
  ]
}
```

### 2.6 新增子域名的标准流程

每次新增一个子域名站点，只需要 **3 步**：

```
Step 1: 在 vercel.json 添加路由
  { "source": "/新名字", "destination": "/新名字.html" }

Step 2: 在 public/ 下新建 HTML 文件
  public/新名字.html

Step 3: 在 index.html 的 links 数组中添加导航卡片
  { name: "xxx", url: "https://新名字.xxx.online", ... }

Step 4: 推送到 GitHub → Vercel 自动部署 ✅
```

## 四、下一步行动

### 4.1 立即可做（不依赖服务器）

1. **在 Vercel 创建项目**
   - 登录 [vercel.com](https://vercel.com)
   - New Project → Import Git Repository（或手动上传）
   - 绑定你的 `xxx.online` 域名
   - 配置 DNS 通配符记录

2. **部署主导航页**
   - 把 `portal/index.html` 作为项目入口
   - 修改 `links` 数组中的 `YOURDOMAIN` 为实际域名

3. **部署成本机器人指南**
   - 把 `cost-robot-ppt.html` 重命名为 `cost.html` 放入项目
