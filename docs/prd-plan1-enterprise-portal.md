# PRD：企业门户 — bojoo.cn 官网 + bojoo.online 聚合站

> 版本：v1.1 ｜ 日期：2026-05-19

---

## 1. 产品概述

宝珠奶酪公司需要两个网站：
1. **bojoo.cn** — 对外官方网站，面向消费者和潜在加盟商，部署在百度智能云（国内）
2. **bojoo.online** — 对内聚合导航站，面向员工和合作伙伴，聚合各 Agent/应用的入口

**部署策略（双轨并行）**：
- bojoo.cn：直接部署在百度智能云，需完成备案
- bojoo.online：**先用 Vercel 跑通 MVP**（1-2 周临时方案），备案完成后迁移到百度智能云，彻底规避跨洋网络被墙风险

---

## 2. 目标用户

| 用户类型 | 站点 | 使用场景 |
|---------|------|---------|
| 消费者 | bojoo.cn | 了解品牌、查看产品、进入小程序 |
| 加盟商 | bojoo.cn | 了解加盟政策、流程、联系方式 |
| 员工 | bojoo.online | 快速找到成本机器人、差评 Agent、BI 看板等工具入口 |
| 管理层 | bojoo.online | 查看经营数据、AI 分析报告 |

---

## 3. 产品目标

### bojoo.cn
- 建立品牌形象，传达品牌价值
- 招商政策透明化，降低咨询成本
- 引导用户进入小程序，提升线上订单转化

### bojoo.online
- 聚合内部工具入口，减少查找成本
- 支持子域名扩展，新增工具只需加链接
- 简洁美观，加载快，无需登录即可访问

## 5. 非功能需求

| 需求 | 说明 |
|------|------|
| 性能 | 首屏加载 < 2s，纯静态无后端延迟 |
| SEO | 百度可收录 bojoo.cn |
| 安全 | HTTPS 证书配置 |
| 可维护性 | 使用 11ty 静态站点生成器抽离公共组件，编译输出纯 HTML |
| 兼容性 | Chrome/Safari/微信浏览器/企微浏览器 |
| 图片资源 | 大图使用 CDN/对象存储（BOS/七牛云/又拍云），HTML 外链引用，减轻百度云服务器带宽压力 |

## 7. 风险与约束

| 风险 | 影响 | 应对 |
|------|------|------|
| Vercel 国内访问不稳定（DNS 污染/IP 连坐） | bojoo.online 员工无法访问 | 先用 Vercel 过渡，备案完成后迁移到百度云 |
| bojoo.online 未备案 | 长期挂 Vercel 有合规风险 | 同步提交百度云备案（已有主体新增域名，1-2 周） |
| 百度云服务器带宽不足 | 首屏加载慢 | 图片使用 CDN/对象存储，HTML 轻量 |
| 品牌文案/图片素材未提供 | 内容空缺 | 用占位符先搭建框架 |
