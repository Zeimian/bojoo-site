# 宝珠官网旧站参考

> 来源：phpweb CMS 建站系统（2018-2020）
> 旧站 URL：http://bojoo.weilaiwz.com/
> 数据库：阿里云万网 MySQL（qdm81470860.my3w.com）
> 备案：沪ICP备2020027373号-1
> 公司：上海宝珠餐饮有限公司

## 旧站技术栈

- **CMS 系统**：phpweb（国内免费 PHP 建站系统）
- **前端**：Bootstrap + jQuery + bxslider + Owl Carousel
- **后端**：PHP + MySQL
- **主机**：阿里云万网虚拟主机

## 旧站首页模块结构

根据 `index_index.htm` 模板，首页包含以下模块（从上到下）：

1. **Hero 轮播** — `{#modAdvsSlides_17269#}` 产品大图轮播
2. **产品展示** — `{#modPhotoClass_17368#}` + `{#modPhotoPic_17350#}` 产品分类 + 图片列表
3. **数据计数器** — 创办时间 2010 年 / 酪的历史 1000 年 / 酿造技艺 40 天 / 一年售出 300 万杯
4. **何为中式酪饮？** — 图文左右布局，"查看更多"链接到 about 页面
5. **加盟宝珠** — 滑动卡片式展示加盟相关图片
6. **宝珠故事** — 新闻列表形式展示品牌故事
7. **大地食材** — 图片列表展示食材来源

## 旧站视觉风格

- 主色系：蓝色系（`#305dc3`、`#03b29c`）— 注意新站点已改为暖色系（`#D4A574`）
- 字体：微软雅黑 + Arial
- 布局：Bootstrap 栅格 + 响应式
- 动画：wow.js 滚动动画 + 计数器动画

## 可借鉴的设计点

1. **数据计数器模块** — 创办时间、销量等数据展示，增强品牌信任感
2. **产品分类切换** — 首页产品分类 Tab 切换
3. **图文左右布局** — "何为中式酪饮" 模块的排版方式
4. **加盟展示滑动卡片** — 多张加盟图片轮播
5. **大地食材** — 食材来源图片展示，增强品牌故事感
